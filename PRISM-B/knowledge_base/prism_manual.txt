# 2. STRATEGY A — ARTIFICIAL INTELLIGENCE VISUALIZATION

# ======================================================

### Trigger: AI, ML, DL, ANN, CNN, RNN, Transformers, Backprop

### Component

`PrismNeuralNetwork`

```
from prism_lib.visuals.neural_net import PrismNeuralNetwork
```

### TEMPLATE (Use for every AI topic)

```python
# SETUP
nn = PrismNeuralNetwork(
    layer_sizes=[3, 5, 4, 2],
    neuron_color=PRIMARY_COLOR
)

nn.scale(0.8).to_edge(RIGHT)

# CREATE NETWORK
self.play(nn.create(), run_time=2)

# FORWARD PASS
self.play(nn.set_activations([
    [1.0, 0.5, 0.2],
    [0.1, 0.8, 0.2, 0.4, 0.1],
    [0.9, 0.1, 0.8, 0.2],
    [1.0, 0.0]
]))
```

    "x = \\frac{-b \\pm \\sqrt{b^2 - 4ac}}{2a}",
